# dorpsstraat-funda-cijfers

Public hourly Funda listing stats (getoond / bekeken / bewaard) for [Dorpsstraat 67](https://dorpsstraat.marcovanhoekelen.nl).

The dashboard HTML stays on Vercel. This repo is **only** the CSV so we do not burn Vercel Hobby's 100 deploys/day cap.

- Source of truth in the vault: `Administratie/Woningen/Dorpsstraat 67 Landsmeer/funda-cijfers.csv`
- Mini peil (`com.marcoos.funda-verkoop-stats`) uploads this file after each sample
- Raw URL used by the dashboard: [funda-cijfers.csv](https://raw.githubusercontent.com/JustMarco88/dorpsstraat-funda-cijfers/main/funda-cijfers.csv)

Not a vault backup. Not secret (the numbers are on the public dashboard).
